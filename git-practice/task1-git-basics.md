# Task 1: Git Basics

## Commands
- git init                    # create a new repo
- git status                  # show current state
- git add <file>              # stage file
- git commit -m "msg"         # save to history
- git log --oneline           # show commits

## 3 Areas of Git
- Working directory → Staging area → Repository

## File states
- Untracked → Modified → Staged → Committed

## Interview Q

Q: Git vs GitHub?

A: Git = local version control tool; GitHub = cloud hosting for Git repos

Q: git add vs git commit?

A: add = stage; commit = save to history
